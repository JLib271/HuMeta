# Analysis recommendations

Researchers recommend analyses for **Module 5** (data analysis) from the HuMeta
Portal's **Recommend** tabs. Each arrives as a pull request adding one JSON file to
`analyses/`. A maintainer checks the method and citation, implements it with an
established open-source package (pingouin in the app, psych or lavaan in the R
script) with tests, checks results against a published example, and merges.

Recommendations of theories and frameworks, instruments, and corrections to the
library go to the HuMeta Instrument Library's repository,
[humeta-library](https://github.com/JLib271/humeta-library/tree/main/suggestions),
and proposed changes to the HuMeta profile to
[humeta-profile](https://github.com/JLib271/humeta-profile/issues).
